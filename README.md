## Proyectos destacados

### [Análisis SuperStore](https://github.com/Rafa-rs4/Proyecto-Analisis-SuperStore)
Pipeline de datos de punta a punta. Limpieza y estandarización con Python (Pandas), modelo en estrella en SQL Server con procedimientos almacenados transaccionales, triggers de auditoría y una capa de vistas, y un dashboard en Power BI con análisis de rentabilidad, eficiencia logística y segmentación de clientes.

`Python` `SQL Server` `T-SQL` `Power BI`

### [ENDES: Big Data y Machine Learning](https://github.com/Rafa-rs4/endes-bigdata-ml)
Modelos predictivos de riesgo en el embarazo y de violencia familiar, construidos con los microdatos de la Encuesta Demográfica y de Salud Familiar (INEI). ETL distribuido y entrenamiento con PySpark (Regresión Logística, Random Forest, Gradient Boosting), entorno contenerizado con Docker y Hadoop, y modelos servidos mediante una API REST con FastAPI.

`PySpark` `Hadoop` `Docker` `FastAPI`

### [GoodHabits](https://github.com/Rafa-rs4/GoodHabits)
Aplicación Android para el registro y seguimiento de hábitos, tareas, meditación, nutrición y actividad física. Arquitectura MVVM con Jetpack Compose, persistencia local con Room y autenticación y almacenamiento en Firebase.

`Kotlin` `Jetpack Compose` `Room` `Firebase`
